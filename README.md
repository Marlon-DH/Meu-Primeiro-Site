# Meu Primeiro Site — Casa Aberta Senac

Protótipo de uma experiência interativa para visitantes criarem seu primeiro site sem precisar conhecer HTML, CSS ou JavaScript.

## Estrutura

- `index.html` — estrutura da aplicação
- `style.css` — visual e responsividade
- `script.js` — interações, prévia ao vivo, upload de imagem e download
- `assets/` — espaço reservado para imagens futuras

## Como usar

1. Abra `index.html` em um navegador.
2. Altere os campos no painel esquerdo.
3. Veja a prévia mudar automaticamente.
4. Clique em **Publicar meu site**.
5. O botão **Baixar meu site** gera uma página HTML independente.

## Ideia para a exposição

O computador pode ficar com `index.html` aberto em tela cheia. A pessoa preenche seu nome, escolhe uma cor, adiciona uma imagem e vê o site nascer na hora.
